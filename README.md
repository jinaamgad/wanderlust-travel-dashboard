# Wanderlust Travel Dashboard

## Overview
Wanderlust is a dynamic travel dashboard web application that provides real-time travel-related information using multiple public APIs.

## Features
- Real-time weather updates  
- Currency exchange rates  
- Holiday information  
- Sunrise & sunset times  
- Dynamic and interactive UI  

## Technologies Used
- JavaScript  
- HTML  
- CSS  
- Public APIs  

## Purpose
This project was built to practice working with APIs and creating dynamic web applications that combine multiple data sources into a single user-friendly dashboard.

## Note
This is a frontend project focused on API integration and UI development.
